# 🏦 Future Bank – Smart Digital Banking Simulator

Future Bank is a **modern digital banking simulator** built using **HTML, CSS, and JavaScript**.
It allows users to create accounts, deposit and withdraw money, and view transaction history — all stored securely using browser local storage.

---

## ✨ Features

✔ Create / Login with customer name & 12-digit account number
✔ Smart name suggestions for returning users
✔ Deposit & withdraw money
✔ Real-time balance updates
✔ Transaction history popup
✔ Local storage data persistence
✔ Clean modern glassmorphism UI
✔ Responsive & animated design

---

## 🖥️ Technologies Used

* HTML5
* CSS3 (Glassmorphism UI + Animations)
* JavaScript (DOM + LocalStorage)

## 🚀 How It Works

### 1️⃣ Login / Create Account

* Enter customer name
* Enter 12-digit account number
* Existing users are recognized automatically

### 2️⃣ Banking Operations

* Deposit money
* Withdraw money
* Balance updates instantly

### 3️⃣ Transaction History

* Click ☰ menu to view history
* Shows deposit & withdrawal records with date & time

---

## 💾 Data Storage

All account details are stored using:

```
localStorage
```

Stored data includes:

* Customer name
* Account number
* Balance
* Transaction history

---

## 🎯 Validation Rules

✔ Account number must be **12 digits**
✔ Withdrawals cannot exceed balance
✔ Amount must be positive
